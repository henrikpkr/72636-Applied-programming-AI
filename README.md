# 72636 Applied Programming with AI

Individual submission with all three course projects. Each one is in its own folder and has its own README.

| # | Project | Folder | Summary |
|---|---------|--------|---------|
| 1 | Browser extension | [browser-extension/](browser-extension/) | Chrome extension (Manifest V3) that converts files to Markdown locally |
| 2 | Books to Scrape | [books-to-scrape/](books-to-scrape/) | Scraper for books.toscrape.com that stores the data in Supabase (Postgres) and shows it on a Next.js dashboard |
| 3 | TVmaze API | [tvmaze/](tvmaze/) | Swipe-style TV show picker built on the TVmaze API, with likes saved in SQLite |

Projects 2 and 3 were first developed in separate repositories and were merged in here with their commit history kept.
